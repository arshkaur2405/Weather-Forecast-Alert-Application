# Weather Forecast & Alert Application

A Python-based Weather Forecast & Alert Application that fetches live weather data using WeatherAPI and generates automated weather alerts, reports, and visualizations.

---

## 🚀 Features

- Live Weather API Integration
- Simulation Mode using Synthetic Data
- Temperature, Humidity & Rain Alerts
- CSV Report Generation
- Weather Charts & Visualization
- Interactive Streamlit Dashboard
- Error Handling & Fallback System

---

## 🛠 Tech Stack

- Python
- Requests
- Pandas
- Matplotlib
- Streamlit
- JSON
- WeatherAPI

## ⚙ Installation

```bash
git clone https://github.com/YOUR_USERNAME/Weather-Forecast-Alert-Application.git

cd Weather-Forecast-Alert-Application

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt
```

---

## 🔑 API Setup

Create `.env` file:

```env
API_KEY=your_api_key_here
```

Get free API key from:

https://www.weatherapi.com/

## ▶ Run Project

### Terminal Version

```bash
python main.py
```
